# 金融团队协作启动器

## 使用方法

当用户询问持仓分析时，启动协作模式：

```
用户：持有588663（科创新能源ETF）多少股，仓位99.95%
```

### 协作流程

**第一步：获取实时数据**

投顾专家先获取ETF实时行情：
- ETF代码：588663（科创新能源ETF）
- 需要获取：净值、涨跌幅、成交量、成分股

**第二步：分发任务**

投顾专家同时召唤：
1. 行业研究员 - 分析新能源/科创板行业趋势
2. 商机助理 - 分析短期交易机会
3. 企业舆情助理 - 分析成分股风险
4. 财富专员 - 分析资产配置

**第三步：汇总分析**

投顾专家综合所有信息，给出最终建议。

## 数据源

### ETF/A股实时行情
```bash
# AkShare 主源 + 核验源守门脚本
python3 ../astock-report/scripts/market_data_guard.py quote 588663.SH --json
```

### 行业数据
```bash
# 使用 akshare-stock 中的行业/概念板块函数，并标注函数名、参数、数据日期
python3 - <<'PY'
import akshare as ak
print(ak.stock_board_industry_name_em().head())
PY
```

使用 AkShare 榜单函数前必须确认函数名、参数、字段含义、数据日期和单位；换手率、成交额、百分比等字段要先做合理性校验，异常值不得直接写入报告。

### 舆情数据
新闻、公告、研报必须保留原文标题、来源、发布时间和链接；搜索摘要只能作为待核实线索，不能补事实或数值。

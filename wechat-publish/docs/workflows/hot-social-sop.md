# 男女对立 / 社会争议 / 焦虑类选题：从热搜到发布的完整 SOP

> 基于 2026-07-09「医学博士迷奸未婚妻案」全流程实战总结

---

## 总览：5 个阶段

```
① 搜热搜 → ② 出选题 → ③ 深挖素材+生成配图 → ④ 写文章（极简风格）→ ⑤ 自动发布
```

每个阶段的产出物、工具、注意事项如下。

---

## ① 搜热搜（10 分钟）

### 目标
抓取**当天实时**微博热搜 / 热文号 / 新闻热点，不能用过时数据。

### 工具
- `WebSearch`（内置）：搜"微博热搜 今日"或具体关键词
- `web_search` skill（用户级）：通过本地 SearXNG 实例，隐私友好
- `wechat-article-search` skill：搜微信公众号已发文章作为参考

### 搜索策略
分两轮：
1. **广撒网**：搜"微博热搜 今天"、"社会新闻 热议"、"男女对立 热点"
2. **定向深挖**：针对感兴趣的词条，搜具体事件细节

### 筛选标准
同时满足以下条件的热点优先：
- ✅ 今天/昨天的实时热搜（有微博排名编号）
- ✅ 涉及男女对立、信任崩塌、社会不公、阶层焦虑
- ✅ 有判决/通报/权威媒体报道（不是纯情绪帖）
- ✅ 争议度高——正反两方都有话说

---

## ② 出选题（15 分钟）

### 产出物
`topic-plan-{日期}-hot.md`，放在 `wechat-publish/articles/` 下。

### 模板结构

每个选题包含 5 个模块：

```markdown
## 选题N：【今日热搜#排名】事件标题——"一句焦虑钩子"

### 热搜词条
- `#具体词条#` 微博热搜排名XX

### 事件概况
- 时间、地点、人物、关键事实（3-5 条 bullet）

### 两极分化点
- **女性视角**：...
- **男性视角**：...
- **法律视角**：...
- **社会视角**：...

### 焦虑钩子
- 3 句话，每句都是一个能让读者"倒吸一口气"的点

### 建议标题
**"标题（克制但有力，不纯粹标题党）"**
```

### 优先级表格

```markdown
| 排名 | 选题 | 热搜排名 | 争议度 | 焦虑感 | 传播力 |
|------|------|---------|--------|--------|--------|
| 1    | ...  | #20     | ★★★★★ | ★★★★★ | ★★★★★ |
```

### 选定标准
- 争议度 + 焦虑感 + 传播力 三项至少两项 ★★★★★
- 有法律/官方事实支撑（避免造谣风险）
- 今天热度正在攀升（不是昨天的旧闻）

### 实战经验
- 用户会要求"最近的热搜"——第一次出的一般热点（彩礼新规等）会被打回，必须用**当天实时微博热搜**
- 推荐首选时要说清楚理由（热度趋势、争议点、事实支撑）

## ③ 深挖素材 + 生成配图（20 分钟）

### 素材深挖

选定选题后，用 `WebSearch` 深搜事件全貌：

| 搜索维度 | 关键词示例 |
|---------|-----------|
| 案件细节 | 当事人姓名、学历背景、判决书内容 |
| 权威报道 | 南方都市报、澎湃新闻、BBC、中国新闻周刊 |
| 专家分析 | 法学教授观点、心理学分析 |
| 延伸背景 | 类似案例、历史判例、相关数据研究 |

### 配图生成

> ⚠️ **经验坑（2026-07-13）**：早期版本用外部图片 API 生成，多次超时失败，退化成「复用上一篇文章的旧图」，结果正文图与封面全是另一案件的图（配图错配）。**正确做法：直接用内置 `ImageGen` 一次生成 4 张正文图 + 1 张封面，绝不跨文章复用图片。** 生成失败就重试 `ImageGen`，不要用旧稿图顶替。

用 **内置 `ImageGen` 工具**（通过 `DeferExecuteTool` 调用）生成 AI 插画，每篇文章 4 张正文图 + 1 张封面：

```
工具：DeferExecuteTool → ImageGen
Prompt 风格：editorial illustration, dramatic lighting, dark mood, concept art
数量：按文章结构，每个关键转折点配一张
存储路径：wechat-publish/articles/images/
文件名：A_{描述}_{时间戳}.png
```

**实战中的 4 张配图**：
1. 精英学历网络暗网（群聊成员背景）
2. 庭审现场遮挡脸部（被告要脸）
3. 亲密关系信任崩塌（未婚妻被迷奸）
4. 打破沉默的受害者（发声勇气）

### 图片要求
- 风格统一（同一种 editorial illustration 调性）
- 不要真人照片（避免肖像权问题）
- 尺寸横版，适合公众号正文宽度
- **必须本题专属**：4 张正文图 + 1 张封面都按本文事件生成，严禁从 `articles/images/` 里挑旧图顶替
- 不要真人照片 / 不要血腥画面（避免肖像权与平台违规）
- HTML 中 `<img src="文件名.png">` 用**纯文件名**（basename），发布脚本从 `ARTICLE_IMAGES_DIR` 按名匹配上传到微信 CDN
- 封面通过 `COVER_IMAGE_PATH` 单独上传，不要塞进正文

## ④ 写文章——极简风格（30 分钟）

### 风格参照：麦杰逊

核心原则：**一个人在跟你说话，不是一堆组件在展示信息。**

### HTML 结构规范

```html
<section style="padding:0;margin:0;">

  <!-- 纯文字段落 -->
  <p style="margin:0 0 1.2em 0;line-height:1.8;font-size:16px;color:#333;">
    正文内容。
  </p>

  <!-- 加粗关键事实 -->
  <p style="margin:0 0 1.2em 0;line-height:1.8;font-size:16px;color:#333;">
    他被判了<strong style="color:#c0392b;"><span leaf="">5年</span></strong>。
  </p>

  <!-- 分隔线 -->
  <p style="margin:0 0 2.4em 0;line-height:1;text-align:center;font-size:12px;color:#999;">—— ✦ ——</p>

  <!-- 图片 -->
  <p style="margin:0 0 1.2em 0;text-align:center;">
    <img src="微信CDN_URL" style="width:100%;max-width:640px;border-radius:4px;" alt="图片说明"/>
  </p>

</section>
```

### 写作规范

| 规则 | 说明 |
|------|------|
| **短段落** | 每段 1-3 句话，不要大段文字墙 |
| **口语化** | 像跟朋友聊天，不像写论文 |
| **反问推进** | "这个案子到底怎么回事呢？""有意思的是什么呢？" |
| **加粗克制** | 只在关键事实/数字处用 `<strong>`，不要频繁加粗 |
| **图片穿插** | 每 4-6 段文字插一张配图，打破纯文字堆砌 |
| **分隔线** | 章节之间用 `—— ✦ ——` 分隔，不用 PART 标题 |
| **金句独立** | 最有力的话单独成段，用 `<strong>` 标红 |

### 标题策略

| 类型 | 示例 | 适用场景 |
|------|------|---------|
| 事实冲击型 | "她被未婚夫迷奸3次，还叫别的男人一起" | 案件类，事实本身足够震撼 |
| 克制留白型 | "迷奸未婚妻3次的医学博士判了5年，她却拒绝作证。" | 有反转/悖论的选题 |
| 焦虑提问型 | "最该保护你的人，成了最危险的人——你凭什么还相信'他不一样'？" | 信任/安全类选题 |

**注意**：标题要克制但有力，不要纯粹标题党。

### 排版禁忌（踩过的坑）

| 禁忌 | 原因 |
|------|------|
| ❌ 警告框 / pill-list / 数据卡 / 踩坑框 | 花哨组件让文章像 PPT，不像对话 |
| ❌ `\u201c` / `\u201d` Unicode 转义 | 公众号编辑器会当成字面文字显示 |
| ❌ 半角引号 `"` 包裹中文 | 应使用全角 `"` `"` |
| ❌ `<span leaf()>` 语法错误 | 正确写法是 `<span leaf="">` |
| ❌ 图片用本地文件名 `src="xxx.png"` | 公众号编辑器无法读取本地文件，必须上传到微信 CDN |

### 引用规范

- 数据来源在文末统一列出（法院判决书、媒体报道名称）
- 不做超出事实的推测
- 对受害者保持尊重，化名处理

## ⑤ 自动发布（10 分钟 + 扫码）

### 脚本
`wechat-publish/publish_gender_article.py`（或其他文章的对应脚本）

### 发布流程（13 步）

```
[1]  打开公众号后台（需扫码登录）
[2]  创建新文章
[3]  上传正文图片到微信 CDN ← 新增！关键步骤
    └─ 逐张通过编辑器工具栏 input[type=file] 上传
    └─ 获取 mmbiz CDN URL，替换 HTML 中的本地路径
    └─ 上传后删除正文中的临时图片
[4]  重新打开编辑器（清空临时上传内容）
[5]  填写标题
[6]  填写作者
[7]  粘贴正文（已替换为 CDN URL 的 HTML）
[8]  上传封面（通过工具栏上传 → 获取 file_id → 设置封面预览）
[9]  填写摘要
[10] 保存草稿 → 获取 appMsgId
[11] 重新加载 → 恢复封面预览 URL（微信保存后会重置）
[12] 发表 → 处理弹窗（AI声明→继续发表→发表→继续发表）
[13] 最终验证（检查页面标题/成功关键词）
```

### 弹窗处理顺序

脚本自动识别并点击：
1. **创作来源声明** → "继续发表"（含 AI 生成图片时会弹出）
2. **发表确认** → "发表"
3. **未开启群发通知** → "继续发表"
4. **微信扫码验证** → 等待用户扫码（脚本等待 12 轮 × 2.5 秒）

### 图片上传原理（关键）

```
本地图片文件
  ↓ set_input_files() 到编辑器工具栏
正文编辑器中出现 <img data-imgfileid="xxx" src="https://mmbiz.qpic.cn/...">
  ↓ 读取 src（CDN URL）和 data-imgfileid（file_id）
  ↓ 删除正文中的临时 <img>
  ↓ 用 CDN URL 替换 HTML 中的本地文件名
  ↓ 重新打开编辑器，粘贴替换后的 HTML
正文图片正常显示 ✅
```

封面图同理：上传到正文 → 获取 URL 和 file_id → 删除正文临时图片 → 手动设置封面预览区域的 background-image 和 hidden input。

### 发布后注意事项

- 保存草稿后微信会重置封面预览 URL → 脚本自动恢复
- 发表完成后的 320003 / 重新登录页面是正常会话过期，不影响发表结果
- 发表需要管理员/运营者微信扫码验证，脚本等待但不会自动完成这步

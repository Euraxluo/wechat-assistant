# 实时热点·社会新闻 题材说明

## 流程差异概述

与通用 skill 基本一致，关键差异在**事实核实**和**配图专属化**：
社会新闻对日期/年龄/进展极度敏感，错一处就失实；配图必须为本事件生成，
绝不能用其他题材（如财经、旧案）的库存图。

## 配图策略（场景清单参考）

以「少年拍门遭捅杀」为例，4 张正文 + 1 封面：
1. 事件场景：夜色中的旧木门 / 巷子
2. 当事人背景：空荡的红色田径跑道（夺冠少年）
3. 情感钩子：抱着手机的母亲剪影
4. 公共讨论：倾斜的正义天平（道德困境）
5. 封面：门 + 跑道 + 月光 的暗调合成

prompt 统一走 `dark moody editorial`，保证整组视觉一致。

## 踩坑 / 经验

- **配图错配（最严重）**：v1 曾复用 7/9 迷奸案旧图（4 张 + 封面全错）。
  根因是流程内 ImageGen 超时后退化为复用旧图。**规则：任何 timeout 都不准回退到旧图，宁可重试或换更快方案。**
- **事实写错**：v1 把案发日写成 5/23（实为 5/24 凌晨近 2 点）、检察院移送写成 7/9（实为 7/3）。
  落笔前必跑 WebSearch 交叉核实。
- **引语标点**：临终遗言应为「妈妈，我好疼，想喝水。」注意逗号与句号。
- **草稿残留**：调试会建多篇同标题草稿，发表后到后台手动删旧稿。

## 标题 / 摘要示例

- 标题：`16岁少年拍门玩闹被捅死，母亲说：错不至死`
- 摘要：`内蒙古16岁田径少年庆祝夺冠后，凌晨拍门玩闹遭36岁男子持刀捅死，临终对母亲说"妈妈我好疼，想喝水"。母亲今日冲上微博热搜第一：孩子有错，但错不至死。案件已于7月3日移送检察院审查起诉。`
